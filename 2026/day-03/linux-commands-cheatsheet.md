1. ls -ltr : Show latest file from a directory
2. mkdir directory_name : Creates a Directory/Folder
3. pwd : Shows current working directory
4. cat file_name : Shows content of a file
5. touch file_name : Creates an empty file
6. cd : Used to change or traverse to a specific directory
7. tail -n n file_name : Shows n line of a file from end
8. head -n n file_name : Shows n line of a file from start
9. vim : Visual Text Editor use to edit or write content in file
10. df -h : Shows disk usage in a human readable format
11. free -h : Shows used and free amount of memory in human readble format
12. sudo : Allows user as to run command as super user
13. grep "error" file_name : Will find word error in file mentioned
14. kill PID : Kills process having mentioned PID
15. rm file_name : deletes the mention file
16. rm -rf folder_name : deletes folder and contents in it 
17. ps aux : Shows all running process
18. chown : change ownership of file
19. chmod : change permission of file 
20. mv : moves file or rename file
21. ping : use to ping or test network connectivity to host
22. ip addr : Shows all network interfaces and their IP adresses
23. dig : Used for querying DNS name for diagnosing domain records
