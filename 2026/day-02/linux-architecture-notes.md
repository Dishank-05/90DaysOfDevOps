Linux is an operating system where kernel is considered heart or core component. 

Core Components of Linux

1. App/User: This is the phase where applications run (Eg: nginx,docker,java)
2. Shell: Shell is a command line interface it takes commands from user and sends it to kernel
3. Kernel: Kernel is heart of linux which acts as a bridge between User/App and Hardware . It is responsible for Process and Memory Management.
4. Hardware: Hardware are physical components like CPU,RAM etc.
